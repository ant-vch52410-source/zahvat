# Захват — задачник

Приложение для телефона (PWA): в течение дня быстро записывать голосом или текстом всё подряд —
траты, идеи, задачи, заметки — и выгружать одним CSV на компьютер, где записи разбираются.
Адрес: https://ant-vch52410-source.github.io/zahvat/ · репозиторий: github.com/ant-vch52410-source/zahvat

## Захват · Запись

  - План: экран по макету; база на телефоне; голос с автоперезапуском; выгрузка CSV и JSON; публикация на GitHub Pages
  - → README.md
- ✅ 2. Метки над микрофоном — Финансы, Идея, Задача, Заметка; выбранная ставится перед текстом при сохранении («Финансы: …»), после сохранения сбрасывается
  - План: ряд меток одинаковой ширины без рамок; подбор размера текста 14→11 px, дальше только иконки; приставка при сохранении; метка в черновике; цветная метка в ленте

## Решения

- Технология — PWA (HTML + CSS + JS без сборщиков), данные — IndexedDB на телефоне, без серверов и аккаунтов.
- На телефоне ничего не разбирается: только голос → текст. Разбор на финансы/идеи — программа на компьютере.
- CSV: UTF-8 с BOM, `;`, `\r\n`; колонки `id; дата_время; ts_utc; текст; источник; выгружено`;
  перед текстом с `= + - @` — апостроф; перенос строки остаётся внутри ячейки.
- Выгруженные записи не удаляются, только отмечаются; правка выгруженной записи делает её снова «новой» (тот же `id`).
- Метка хранится внутри текста («Финансы: …»), отдельной колонки нет.
- Публикация — GitHub Pages (публичный репозиторий, в нём только код). Обновление: поднять `VERSION` в `sw.js`, затем push.
- Проверка без Node.js: тесты — `tests/tests.html`, без сети — `tests/offline.html` в Edge без окна.

## Структура проекта

- `index.html`, `style.css` — экран; `app.js` — логика экрана; `core.js` — чистые функции (CSV, даты, метки);
  `db.js` — база; `speech.js` — голос; `sw.js` — офлайн-кэш; `manifest.webmanifest`, `icons/` — установка.
- `tests/` — тесты и проверка без сети; `tools/make_icons.py` — значки; `README.md` — инструкция.
