# Захват — быстрые записи на телефоне

Одно поле на всё. В течение дня наговариваешь или пишешь: «виза 500 кальян», «мир 800 еда», идею, заметку.
Всё попадает в одну ленту. Вечером (или когда удобно) выгружаешь одним CSV-файлом на компьютер, где запись
разбирается на финансы, идеи и прочее. На телефоне ничего не разбирается, только голос превращается в текст.

- Приложение — PWA: сайт, который ставится на главный экран Android как обычное приложение.
- Работает без интернета (кроме распознавания речи Chrome — ему нужна сеть).
- Данные хранятся только на телефоне, никаких аккаунтов, серверов и отправки куда-либо.
- Размер — около 60 КБ.

## Файлы

| Файл | Что это |
|---|---|
| `index.html`, `style.css` | экран |
| `app.js` | ввод, лента, правка, меню, выгрузка, резервная копия |
| `core.js` | чистые функции: CSV, даты, отбор, объединение копий |
| `db.js` | база на телефоне (IndexedDB) |
| `speech.js` | голосовой ввод |
| `sw.js` | кэш для работы без сети |
| `manifest.webmanifest`, `icons/` | установка на главный экран, значок |
| `tools/make_icons.py` | рисует значки заново: `python tools\make_icons.py` |
| `tests/tests.html` | тесты функций CSV, дат, копий, склейки голоса |
| `tests/offline.html` | проверка работы без сети (см. «Проверка») |

## Как пользоваться

1. Открыть «Захват».
2. Нажать микрофон и говорить. Можно и просто печатать. Серым показывается то, что ещё распознаётся.
3. Нажать «Сохранить». Поле очищается, запись появляется в ленте «Сегодня».

- Нажатие на запись открывает правку и удаление. После удаления есть «Отменить».
- Лупа включает поиск по всем записям: регистр и «ё/е» не важны.
- Недописанный текст не теряется: черновик сохраняется сам и вернётся после закрытия приложения.
- Значок 🎙 в ленте означает, что запись надиктована, ⌨ — набрана вручную. На ПК это колонка `источник`.

## Публикация на GitHub Pages

Для микрофона и установки на телефон нужен адрес `https://`. Бесплатный вариант — GitHub Pages.
На бесплатном тарифе репозиторий для Pages должен быть **публичным**. В нём лежит только код,
записи остаются на телефоне.

Один раз, в PowerShell (`gh` уже установлен; если не входил — сначала `gh auth login`):

```bash
cd C:\Users\Sergey\Documents\Projects\Android
```
```bash
git init
```
```bash
git add .
```
```bash
git commit -m "Захват: первая версия"
```
```bash
git branch -M main
```
```bash
gh repo create zahvat --public --source . --push
```
```bash
gh api -X POST "repos/{owner}/zahvat/pages" -f "source[branch]=main" -f "source[path]=/"
```

Через 1–2 минуты приложение будет по адресу `https://ВАШ_ЛОГИН.github.io/zahvat/`
(точный адрес покажет `gh api "repos/{owner}/zahvat/pages" --jq .html_url`).

**Обновление.** Поменял код — увеличь `VERSION` в `sw.js` (`zahvat-v1` → `zahvat-v2`), затем:

```bash
git commit -am "Захват: обновление"
```
```bash
git push
```

На телефоне закрой и открой приложение (иногда дважды): новая версия подхватится, записи останутся.

## Установка на Android

1. Открыть адрес приложения в **Chrome**.
2. Меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
3. На главном экране появится «Захват» с синим значком микрофона. Дальше открывать его оттуда.

## Микрофон

- При первом нажатии на микрофон Chrome спросит разрешение — «Разрешить».
- Если случайно запретил: Chrome → ⋮ → Настройки → Настройки сайтов → Микрофон → разрешить для адреса приложения.
  Ещё проверь Настройки Android → Приложения → Chrome → Разрешения → Микрофон.
- Распознавание речи в Chrome работает **через интернет**. Без сети приложение так и скажет;
  текст при этом набирается и сохраняется как обычно.
- Запасной вариант — микрофон на клавиатуре Gboard: он вводит текст прямо в поле. Если в Gboard скачан
  русский язык для офлайн-распознавания, это работает и без сети.
- Chrome сам обрывает распознавание после паузы. Приложение перезапускает его, пока ты не нажмёшь микрофон
  ещё раз. Кнопка «Сохранить» во время записи останавливает её и сохраняет всё, включая недоговорённое.

## Выгрузка на компьютер

Меню ⋮ в правом верхнем углу. Вверху меню — сколько записей новых (ещё не выгружались) и когда была выгрузка.

- **Поделиться CSV** — выгружает новые записи через меню Android: Telegram «Избранное», почта, Google Диск,
  «Сохранить на устройство». Если отменить отправку, записи не отмечаются выгруженными.
- **Скачать CSV** — файл попадает в «Загрузки» телефона. Оттуда — по USB или любым способом.
- **Копировать текст** — весь CSV в буфер обмена (запасной вариант).
- **Выгрузить за период / всё…** — те же три способа, но за выбранные даты или вообще всё.
- **Отменить отметку выгрузки** — если файл не дошёл: записи последней выгрузки снова станут «новыми».

Выгруженные записи **не удаляются** с телефона, а только отмечаются (в ленте — галочка у времени).
Имя файла — `zahvat_ГГГГ-ММ-ДД_ЧЧММ.csv`, только латиница и цифры.

## Формат CSV

```
id;дата_время;ts_utc;текст;источник;выгружено
```

| Колонка | Что внутри |
|---|---|
| `id` | постоянный уникальный номер записи — по нему убираются дубли |
| `дата_время` | местное время телефона: `02.10.2026 14:20:05` |
| `ts_utc` | то же время по UTC в ISO 8601: `2026-10-02T09:20:05.000Z` — для скриптов |
| `текст` | запись как есть |
| `источник` | `voice` — надиктовано, `text` — набрано |
| `выгружено` | когда эта запись выгружалась **раньше**; пусто — впервые |

Правила, чтобы русский Excel открывал файл двойным щелчком:
- кодировка UTF-8 с меткой BOM — кириллица читается сразу;
- разделитель `;`, строки разделены `\r\n`;
- текст с `;`, кавычками или переносами строк взят в кавычки, кавычки внутри удвоены;
  перенос строки остаётся внутри ячейки — Excel показывает его как перенос в ячейке;
- текст, начинающийся с `=`, `+`, `-` или `@`, получает впереди апостроф `'`, чтобы Excel не принял
  его за формулу. Пример: `'-500 возврат`. При разборе на ПК этот апостроф нужно убрать (см. запрос ниже);
- записи идут по времени, от старых к новым.

**Повторы id.** Если запись поправить после выгрузки, она снова станет «новой» и придёт в следующем файле
с тем же `id`. При сборе всех файлов оставляй версию из **самого свежего файла**.

## Excel и Power Query

**Просто посмотреть** — двойной щелчок по файлу.

**Собирать все выгрузки в одну таблицу:**
1. Складывай файлы `zahvat_*.csv` в одну папку, например `C:\Users\Sergey\Documents\Захват`.
2. Excel → Данные → Получить данные → Из других источников → Пустой запрос.
3. Главная → Расширенный редактор → вставить запрос ниже (путь к папке поправить) → Готово.
4. Закрыть и загрузить. Новые файлы в папке → Данные → Обновить всё.

```
let
    Папка = "C:\Users\Sergey\Documents\Захват",
    Файлы = Folder.Files(Папка),
    ТолькоCSV = Table.SelectRows(Файлы, each Text.StartsWith([Name], "zahvat_") and [Extension] = ".csv"),
    Прочитано = Table.AddColumn(ТолькоCSV, "Данные", each Table.PromoteHeaders(
        Csv.Document([Content], [Delimiter = ";", Encoding = 65001, QuoteStyle = QuoteStyle.Csv]),
        [PromoteAllScalars = true])),
    Нужное = Table.SelectColumns(Прочитано, {"Name", "Данные"}),
    Развёрнуто = Table.ExpandTableColumn(Нужное, "Данные",
        {"id", "дата_время", "ts_utc", "текст", "источник", "выгружено"}),
    Типы = Table.TransformColumnTypes(Развёрнуто, {{"дата_время", type datetime}}, "ru-RU"),
    // Свежие файлы — первыми: при повторе id остаётся последняя версия записи
    Сортировка = Table.Buffer(Table.Sort(Типы, {{"Name", Order.Descending}})),
    БезДублей = Table.Distinct(Сортировка, {"id"}),
    // Убираем защитный апостроф перед = + - @
    БезАпострофа = Table.TransformColumns(БезДублей, {{"текст", each
        if Text.StartsWith(_, "'") and List.Contains({"=", "+", "-", "@"}, Text.Middle(_, 1, 1))
        then Text.Middle(_, 1) else _, type text}}),
    Итог = Table.Sort(БезАпострофа, {{"дата_время", Order.Ascending}})
in
    Итог
```

Имена файлов `zahvat_ГГГГ-ММ-ДД_ЧЧММ` сортируются по алфавиту ровно в порядке времени, поэтому сортировка
по `Name` — это сортировка по дате выгрузки. Дальше этот запрос — источник для разбора на финансы и идеи.

## Резервная копия

- Меню ⋮ → **Резервная копия JSON** — полная копия всех записей в «Загрузки»
  (`zahvat_backup_ГГГГ-ММ-ДД_ЧЧММ.json`). Перенеси её с телефона, например в Telegram «Избранное».
- Меню ⋮ → **Восстановить из JSON** — выбрать файл. Записи объединяются по `id` без дублей:
  новые добавляются, а у совпадающих остаётся более свежая правка. Восстанавливать один файл
  несколько раз безопасно.
- Когда это нужно: очистка данных Chrome, удаление приложения, новый телефон. Делай копию раз в неделю.
  Приложение просит Chrome не стирать базу при нехватке места, но от ручной очистки данных это не спасает.

## Проверка без сети (для разработки)

`tests/offline.html` проверяет, что приложение открывается из кэша и сохраняет записи без сервера.
Шаг 1 (`?phase=1`) — при работающем сервере, шаг 2 (`?phase=2`) — после его остановки. Результат виден
на странице. Ещё он отправляется в журнал сервера-приёмника на порту 8766, если тот запущен
(так проверка шла в Edge без окна).
