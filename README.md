# Захват — версия 9.3.1

Быстрые записи на Android: https://ant-vch52410-source.github.io/zahvat/
Приложение устанавливается из Chrome на главный экран. Данные остаются в IndexedDB телефона;
GitHub Pages раздаёт только код. Для голосового ввода Chrome требуется сеть; текст, формы,
история и QR по снимку работают без сети после первого открытия.

## Главный экран

Общее поле текста, «Стереть» с возвратом, «Сохранить», шесть иконок разделов.
Микрофон закреплён справа внизу экрана во всех разделах. Недописанное сохраняется как черновик.

- **Финансы:** расход / доход / перевод; переключатель **План** создаёт покупку для «Финансы → Прогноз → Покупки» без списания денег; сумма своей клавиатурой, счета, частые статьи в два столбца,
  поиск статьи с фильтрацией, дата с ручным вводом ДД.ММ.ГГГГ и стрелками ±1 день.
  Без суммы текст сохраняется как заметка. Для перевода выбираются разные счета.
- **Задачи:** дата, время, важность и проект; «Сегодня», «Завтра», «Без срока».
- **Заметки:** папка, теги и «Важно».
- **Идеи:** проект/тема и теги; из истории идею можно перенести в форму новой задачи.
- **Время:** занятие, проект, день, начало и конец; длительность пересчитывается.
- **Работы:** клиент, проект, выполненная работа, фиксированная сумма и день.

Все записи: поиск, фильтры раздела и доставки, правка и удаление с отменой. Неотправленные всегда сверху с кнопкой «ОТПРАВИТЬ». Ниже — отдельные группы CSV: тонкая линия, маленькая дата/время и число записей. Значок двух стрелок повторяет CSV выбранной группы. Фильтр не меняет её исходный состав.
Новая запись с полями редактируется через «Изменить поля» до выгрузки. После выгрузки правка
производится в Органайзере: один id не создаёт вторую запись при повторном импорте.

## Справочники

В Органайзере: меню значка в трее → **Справочники для «Захвата»**.
На рабочем столе появится `zahvat_catalog.json`. Перенесите файл на телефон;
меню «Захвата» → **Загрузить справочники / квитанцию**.

Каталог содержит счета, статьи, клиентов, проекты, папки заметок и типы занятий. В нём нет
балансов, банковских номеров, операций, текстов заметок или паролей. Справочники должны
происходить из того Органайзера, который будет принимать записи. Старые файлы txt с разделами
`[Счета]` и `[Статьи]` также загружаются, но не содержат справочники остальных модулей.

## Передача на компьютер

1. Меню → «Поделиться CSV», «Скачать CSV» или «Копировать текст».
2. На компьютер передаётся `zahvat2_ГГГГ-ММ-ДД_ЧЧММ_идентификатор.csv`; положите его на рабочий стол.
3. В обновлённом Органайзере нажмите кнопку «С телефона» на пульте.
4. Финансовые операции идут в Финансы; задачи, заметки и идеи — в Планировщик;
   интервалы — в Часы; работы — в Работы. QR-чек ожидает утверждения в Финансах.
5. Квитанция `zahvat_receipt.json` экспортируется на ПК отдельно. Если она получена, загрузите её обратно в «Захват» через
   пункт справочников/квитанции, чтобы видеть подтверждение приёма.

«Выгружено» означает создание/передачу файла; «Принято на ПК» — подтверждение от приёмника.
Подтверждение относится только к той же версии записи. «Требует внимания» содержит причину ошибки.
Файловый обмен сохраняется: ни локальный сетевой сервер, ни облако для данных не нужны.

Новые имена **zahvat2_** намеренно отличаются от старых: старый запущенный приёмник не должен
разбирать структурированный перевод как обычную финансовую фразу. Обновлённый приёмник
принимает оба имени. После обновления кода Органайзера его меню подхватится при штатном перезапуске.
До перезапуска можно из корня Organizer_KAA использовать:

```powershell
.venv\Scripts\python tools\zahvat_exchange.py catalog
.venv\Scripts\python tools\zahvat_exchange.py receive
```

Неизвестный клиент, проект, статья, неустановленный модуль и ошибки остаются в очереди Органайзера.
Интервалы времени не перезаписывают существующие пересекающиеся интервалы; требуется разбор.
Работа с фиксированной суммой не считается оплатой. Задача без срока попадает на день захвата
с явной пометкой «срок не назначен»: у текущего Планировщика нет отдельного списка без даты.

## Формат обмена и копии

CSV — UTF-8 с BOM, разделитель `;`, переводы CRLF, стандартное экранирование кавычек и переносов.
Первые шесть столбцов сохранены:

```
id;дата_время;ts_utc;текст;источник;выгружено;данные
```

`данные` — объект JSON: `v:1`, `kind`, `text` и поля формы; `revision` — время последней правки.
Суммы — целые копейки, дата операции отдельно от времени захвата, ссылки справочников — id + имя.
У старых записей дополнительное поле пустое: они принимаются прежним обработчиком меток.
Защита от Excel-формул и апостроф сохраняется. Повтор id уже принятой записи не создаёт дубль.

Меню → «Резервная копия JSON» сохраняет все записи, их поля, статусы и настройки справочников.
«Восстановить из JSON» объединяет по id, выбирая более свежую правку. Старые копии поддерживаются.
Выгрузка не удаляет записи; есть отмена отметки последней выгрузки. Состав группы, исходный CSV и имя файла сохраняются одной транзакцией с отметками. Повтор передаёт прежние байты, id и revision, не добавляя новую очередь и не создавая группу заново. Даже после удаления исходных записей заголовок сохранённого CSV остаётся доступен для повтора. Старые записи сгруппированы по сохранённому времени прежней выгрузки. JSON-копии включают группы; при восстановлении группы объединяются по id. Отмена Android «Поделиться»
не отмечает записи выгруженными. Ручное удаление данных Chrome удаляет локальную базу — копии
следует хранить отдельно от телефона.

## Диктовка и чеки

Сохранён механизм версии 8: отдельные фразы с автопродолжением, результаты по индексам,
защита от поздних событий старой сессии; последний предварительный текст включается при сохранении.
В неподдерживаемом браузере можно использовать микрофон клавиатуры Gboard.

QR: камера, «Снять», «Галерея», приближение и перемещение снимка. BarcodeDetector с локальным jsQR
в качестве запасного распознавателя; повтор одинакового QR не сохраняется. Фотографии не выгружаются,
передаётся строка фискального QR; позиции получает и утверждает Органайзер.

## Обновление и проверки

APP_VERSION в `app.js` и VERSION в `sw.js` равны 9.3.1. При установке кэш обновляется мимо HTTP-кэша;
добавлен `capture.js`. Обновление «Захвата» удаляет только его прежние кэши `zahvat-v*`, не кэши «Разбора».

- `node tests/run.mjs` — 51 чистая проверка CSV, дат, копий и диктовки.
- `node tests/browser.mjs` — временный профиль Edge, HTTP только на 127.0.0.1; диктовка с управляемыми
  ответами, IndexedDB, шесть рабочих форм, дата, переводы, метаданные CSV и резервных копий, ширина 360.
  Это не проверка настоящего микрофона и камеры Android.
- `tests/tests.html` — чистые проверки в браузере; `tests/offline.html` — проверка кэша без сети.

Схема: `app.js` — ввод/история/QR/выгрузка; `capture.js` — формы разделов;
`core.js` — чистые преобразования; `db.js` — IndexedDB; `speech.js` — диктовка;
`index.html`/`style.css` — интерфейс; `sw.js` — офлайн.

По умолчанию выбран счёт «Виза», дата — сегодня. Явно изменённые поля незавершённого черновика сохраняются. План покупки: название, положительная сумма, статья расхода и дата; источник — общая подушка, реальный счёт оплаты сохраняется. Покупки используют payload v:2 (planned:true); прочие записи — прежний v:1. Старый приёмник отклонит новую покупку, не превратив её в расход. При открытом черновике/варианте прогноза приём ждёт рабочего плана.

## Запуск и работа без интернета (9.3)

При каждом открытии выбраны **Финансы**, сегодняшняя местная дата телефона и выключенный **План**.
Черновики разделов и плана покупки хранятся отдельно. Незавершённая задача или покупка не теряется:
перейдите в соответствующий раздел или включите План. План покупки при запуске не превращается в факт.

Один раз откройте новую версию с интернетом и дождитесь строки **«Версия 9.3.1 · Готово без интернета»** в меню.
После этого запуск, текстовые формы всех шести разделов, справочники, поиск, правка, удаление/отмена,
создание CSV, выбор прежней группы и JSON-копии выполняются локально. QR-библиотека также хранится локально.
Голосовой ввод Chrome требует связи. Передача созданного файла через Telegram, почту и другие сетевые приложения
зависит от связи уже в выбранном приложении; без связи можно сохранить CSV в файлы телефона.

Проверки: `node tests/run.mjs` (51), `node tests/batches.mjs` (10), `node tests/export-runtime.mjs` (7).
Последние проверяют неизменность CSV, старые группы/копии, отмену Android, ошибку базы, параллельные нажатия,
правку во время передачи и возврат прежней группы при отмене отметки. Это чистые проверки без управления браузером.
Проверка интерфейса и автономного запуска выполнялась в Codex IAB на отдельном тестовом адресе с вымышленными данными.
Физический телефон и выбор приложения в Android-панели «Поделиться» проверяются отдельно.

Исправление 9.3.1 (06.11.2026): у основных кнопок окна выгрузки и повторной отправки восстановлен акцентный фон; белый текст больше не оказывается на белом фоне. Формат CSV, данные и поведение отправки не менялись.
